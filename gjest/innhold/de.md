## Ankunft {#ankomst}

### Parken {#parkering}

Sie können an der Hütte parken. Es gibt auch Parkplätze oberhalb der Hütte. Wenn Sie oben parken:

1. Fahren Sie zuerst zur Hütte hinunter und laden Sie das Gepäck aus.
2. Fahren Sie dann denselben Weg zurück und parken Sie auf den Plätzen oberhalb der Hütte.

### Mautstraße {#bom}

Der Weg zur Hütte ist eine private Mautstraße. Sie müssen jede Durchfahrt selbst bezahlen, **innerhalb von 48 Stunden**.

1. Gehen Sie auf [youpark.no](https://youpark.no) und tippen Sie auf „Betal passering“ (Durchfahrt bezahlen). Sie kommen auch über [norgesbom.no/betalpassering](https://norgesbom.no/betalpassering) dorthin.
2. Geben Sie das Kennzeichen Ihres Autos ein. Mehr brauchen Sie nicht.
3. Bezahlen Sie mit Vipps oder Bankkarte.

Das gilt für norwegische und ausländische Autos.

> ! Diese Mautstraße gehört nicht zu Autopass oder Epass24. Auch mit einer Mautbox müssen Sie selbst auf der Webseite bezahlen, innerhalb von 48 Stunden.

**Fahren Sie die Straße mehrmals?** Legen Sie ein Benutzerkonto auf youpark.no an und hinterlegen Sie Ihre Bankkarte. Dann werden die Durchfahrten automatisch abgebucht.

## Die Hütte benutzen {#bruk}

### Der Kamin {#peisen}

> ! Verwenden Sie zum Anzünden nie Grillanzünder-Flüssigkeit, Benzin oder andere Flüssigkeiten.

1. Stellen Sie die Lüftung der Hütte auf niedrig. So zieht der Kamin am besten. Manchmal hilft es, die Terrassentür einen Spalt zu öffnen.
2. Der Hebel unter der Kamintür regelt die Luft. Schieben Sie ihn ganz auf, bevor Sie anzünden.
3. Legen Sie große Holzscheite nach unten, darauf mittlere, dann kleine. Ganz oben kommen Anzündholz und ein Anzünder.
4. Zünden Sie mit einem langen Streichholz oder einem Feuerzeug an.
5. Schließen Sie die Kamintür ganz, sobald das Anzündholz brennt.
6. Wenn die Flammen ruhig brennen, können Sie den Hebel in die Mitte schieben. Dann hält das Holz länger.
7. Legen Sie nur Holz nach, wenn Sie Glut und keine Flammen sehen. Öffnen Sie die Tür langsam.

**Fertig für heute?** Wenn keine Flammen mehr da sind, schließen Sie die Tür und schieben Sie den Hebel ganz zu.

> ! Wird der Kamin zu heiß? Versuchen Sie nicht, das Feuer zu löschen, und nehmen Sie kein brennendes Holz heraus. Schieben Sie den Hebel etwas Richtung zu, aber nicht ganz. Öffnen Sie die Fenster. Kommen Rauch oder Feuer in den Raum: Rufen Sie 110 an.

![Der Hebel unter der Kamintür](bilder/peis-spak.jpg)

### Der Badezuber („stampen“) {#stampen}

„Stampen“ ist ein großer Badezuber aus Holz, der draußen steht. Das Wasser wird mit Holz in einem kleinen Ofen an der Seite des Zubers geheizt.

1. Nehmen Sie die Plane ab. Falten Sie sie mit der Innenseite nach innen.
2. Schließen Sie die Ablassventile. Sie sitzen unten auf der linken Seite des Ofens.
3. Der Gartenschlauch liegt im Saunabad. Schließen Sie ihn an den Wasserhahn draußen an und füllen Sie den Zuber.
4. Füllen Sie, bis das Wasser **über dem oberen Loch** steht, bevor Sie einheizen. Sonst entsteht eine Luftblase, und das Wasser wird kaum warm.
5. Ist das Wasser beim Einfüllen braun? Lassen Sie es laufen, bis es klar ist.
6. Drehen Sie das Wasser ab, wenn der Zuber voll ist. Legen Sie den Schlauch zurück ins Saunabad, damit er nicht einfriert.
7. Legen Sie den Deckel vorsichtig ab, am besten auf die Plane an der Wand.
8. Treten Sie in die Fußbadwanne, bevor Sie in den Zuber steigen. So kommen kein Sand und Kies ins Wasser.
9. Legen Sie nach dem Baden immer den Deckel wieder auf.

![Der Ofen. Die Ablassventile sitzen unten auf der linken Seite.](bilder/stamp-tommekraner.png)

**Licht am Badezuber:** Die Steckdose für das Licht am Zuber ist vorübergehend entfernt. Legen Sie ein Verlängerungskabel von der Hüttenwand. Im Kellerflur gibt es außerdem eine Außenlampe, die Sie benutzen können.

### Die Sauna {#badstua}

- Gießen Sie nicht mehr Wasser auf den Saunaofen, als er verdampfen kann.
- Stellen Sie die Kaltwasserwanne nicht direkt neben die Türen. Sonst bildet sich schnell Eis darum.

### Wasser {#vann}

- Lassen Sie den Schlauch draußen nie unter Druck, wenn er nicht benutzt wird. Alles friert sehr schnell ein.
- Vermeiden Sie Wasser auf dem Parkett. Es wird sehr schnell unschön.

### Starker Wind {#vind}

- Ist starker Wind angesagt? Sichern Sie Stühle und Feuerschale. Sie können wegfliegen.
- Achten Sie darauf, dass die Türen nicht ganz aufschlagen.

### Gut zu wissen {#nyttig}

- Im Wohnraum im Keller steht eine zusätzliche Tischplatte, neben dem Kühl- und Gefrierschrank.

### Der Kamin zieht schlecht {#p-peis}

1. Stellen Sie die Lüftung der Hütte auf niedrig.
2. Öffnen Sie die Terrassentür einen Spalt.
3. Schieben Sie den Hebel unter der Kamintür ganz auf.
4. Ist es draußen mild? Legen Sie etwas kleines Holz nach, damit die Flammen wieder größer werden.

### Der Badezuber wird nicht warm {#p-stamp}

Das Wasser muss über dem oberen Loch stehen, bevor Sie einheizen. Sonst entsteht eine Luftblase. Füllen Sie mehr Wasser nach.

## Vor der Abreise {#avreise}

### Drinnen {#avreise-inne}

- Räumen Sie alle Lebensmittel und Getränke weg.
- Schalten Sie die Spülmaschine ein. Spülen Sie von Hand, was nicht hineinpasst.
- Blasen Sie alle Kerzen aus.
- Lassen Sie alle Jalousien herunter.
- Hängen Sie nasse Handtücher zum Trocknen auf. Legen Sie sie nicht zur Bettwäsche.
- Lassen Sie alle Türen in der Hütte offen, damit die Luft zirkuliert.
- Ist etwas kaputtgegangen? Bitte sagen Sie uns Bescheid.

### Draußen {#avreise-ute}

- Bringen Sie allen Müll zur Müllstelle direkt nach der Schranke, auf der linken Seite.
- Haben Sie die Feuerschale benutzt? Ziehen Sie die Abdeckung darüber und befestigen Sie sie am Pfosten.
- Hängen Sie die Schneeschaufeln an die Schiene an der Wand.
- Decken Sie nicht benutztes Holz für den Badezuber gut ab, damit es nicht nass wird.
- Schließen und verriegeln Sie alle Türen und Fenster.

### Der Badezuber {#avreise-stampen}

1. Pumpen Sie das ganze Wasser mit der Lenzpumpe ab. Öffnen Sie gleichzeitig das Ventil links neben dem Ofen.
2. Nehmen Sie gern einen Wasserschieber, damit kein Wasser am Abfluss stehen bleibt. Es kann einfrieren.
3. Legen Sie den Deckel auf und ziehen Sie die Plane über den Zuber.
4. Befestigen Sie die Plane unter der Treppe und legen Sie Steine darauf, damit sie nicht wegweht.
